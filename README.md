# 🧱 Block Blast

A colorful single-file HTML5 block puzzle game. Drag block pieces onto the 8×8 board, fill full rows or columns to blast them away, and chase combo bonuses!

## How to Play

- **Drag** one of the 3 block pieces from the tray onto the board
- **Fill a full row or column** to blast it — each cleared line scores big bonus points
- 🔥 Clear lines on consecutive moves to build a **COMBO** multiplier
- The game ends when **no piece fits** anywhere on the board — plan ahead!

## Features

- 20+ block shapes in bright candy colors with 3D-style shading
- Juicy clear effects: light beams, particle bursts, screen shake, and comic-style banners (NICE! GREAT! AWESOME! UNSTOPPABLE!)
- Synthesized sound effects via Web Audio API (no audio files needed)
- Score popup animations and a persistent best score (localStorage)
- Restart anytime with the ⚙️ button

## Run It

Just open `index.html` in any modern browser — no build step, no dependencies, no server required. Works with both mouse and touch.

## Tech

- Single HTML file, vanilla JavaScript + DOM/CSS (no canvas, no libraries)
- Web Audio API for all sound effects
